# 光合作用小測驗高互動性與遊戲化升級計劃

這份計劃旨在將原本較為靜態的單選題測驗，改造為一個**富含視覺特效、豐富互動題型、遊戲化機制**的「光合作用知識冒險」。這不僅能 wow 使用者，更能作為學生快樂學習的優質範本。

---

## 💡 升級設計亮點

我們的升級方案包含以下四大核心互動要素：

### 1. 🎮 遊戲化核心機制 (Gamification Engine)
* **生命值系統 (HP / Hearts)**：
  * 畫面上方顯示 `❤️ ❤️ ❤️` 三顆精美心形。
  * 答錯或倒數超時會扣除一顆心。
  * 當心形扣光時，會觸發**「挑戰失敗 💔」**的互動畫面，並提供「恢復藥水（重新挑戰）」按鈕。
* **時限倒數計時器 (Round Timer)**：
  * 每題限時 **15 秒**，以頂部精美的線性彩色光條（或圓環）顯示。
  * 隨時間減少，光條由綠變黃；最後 5 秒轉為紅色並觸發「呼吸閃爍」警示特效。
  * 超時將自動視為答錯，扣除生命值並展示解析。
* **即時動態特效與反饋**：
  * **答錯震動 (Visual Shake)**：選錯時，題目卡片會產生輕微的左右快速抖動 CSS 動畫，強化錯誤反饋。
  * **答對粒子效果 (Confetti Burst)**：答對時，在點選按鈕周圍觸發綠葉與金光閃爍的微型粒子噴灑動畫。

### 2. 🧩 多樣化高互動題型 (Interactive Question Types)
原本只有單一的單選題，我們將題庫與操作模式升級為三種不同維度的互動方式：
* **第一關：經典挑戰（單選題）**
  * 答題限時，選項點擊時有微動畫與粒子爆裂效果。
* **第二關：光與碳的歸宿（互動分類題 / Drag & Drop or Click-to-Categorize）**
  * 畫面上散落著光合作用的原料與產物卡片（如 `H₂O`、`CO₂`、`O₂`、`光能`、`ATP`、`NADPH`、`葡萄糖`）。
  * 學生需要點擊卡片將它們正確放置到**「光反應籃子 ☀️」**或**「卡爾文循環籃子 🌀」**中。
  * 籃子會有吸收卡片的縮放動畫，滿滿的動態操作感！
* **第三關：合成之路（步驟排序題 / Process Ordering）**
  * 給定光合作用發生的 4 個關鍵步驟卡片，但順序是混亂的。
  * 學生可以透過點擊「🔼 上移」或「🔽 下移」按鈕來動態調整卡片位置，將其排列成正確的生理作用順序。

### 3. 🏆 榮譽成就徽章與 3D 翻轉錯題卡 (Badges & Flashcard Review)
* **精美成就徽章 (Achievement Badges)**：
  * 根據最終的答對題數與賸餘生命值，頒發專屬的成就徽章。
  * 徽章採用現代的**玻璃擬態 (Glassmorphism)** 搭配漸層霓虹發光：
    * 滿分或完美通關：頒發 **「光合大師 👑 (Photosynthesis Master)」**。
    * 答對 4 題：頒發 **「綠葉守護者 🌿 (Leaf Guardian)」**。
    * 答對 3 題：頒發 **「陽光新芽 🌱 (Sunny Sprout)」**。
    * 答對 2 題以下：頒發 **「暗室小草 🍄 (Shade Sprout)」**。
* **3D 卡片翻轉複習 (Flashcard Review Mode)**：
  * 測驗結束後，若有錯題，學生可以點擊「複習錯題卡片」。
  * 錯題卡片會以精緻的 3D 翻轉動畫呈現：
    * **正面**：顯示問題與學生的錯誤解答，帶有紅色警告邊框。
    * **點擊卡片**：卡片會平滑翻轉 180 度到**背面**，顯示綠色質感底稿、正確答案與超詳細的科學原理註解。

## 🛠️ 預計修改與新增的程式碼結構

我們將直接在 [index.html](file:///c:/Biology/index.html) 中進行升級，不需引入額外的大型框架，僅使用純 CSS3 動畫與 Vanilla JS 來實現，這非常適合學生學習其背後的底層技術：

### 1. CSS 樣式新增 (`<style>`)
* `.heart-container`, `.heart`：愛心生命值樣式與扣血時的破碎/縮小動畫。
* `.timer-bar`, `.timer-fill`：計時器進度條與紅色警告閃爍動畫 (`@keyframes pulse-red`)。
* `.shake`：答錯時卡片左右震動的動畫 (`@keyframes shake`)。
* `.particle`：答對時噴灑的綠葉/金粒子動畫元素。
* `.drag-quiz`, `.basket`, `.draggable`：分類題專用的籃子與拖放/點擊卡片樣式。
* `.order-quiz`, `.order-item`：排序題的卡片樣式與移動動畫。
* `.badge-container`, `.badge`：玻璃擬態發光徽章與旋轉浮動效果。
* `.flashcard-wrapper`, `.flashcard`, `.flashcard-front`, `.flashcard-back`：3D 翻轉卡片所需的 `perspective`、`transform-style: preserve-3d` , `backface-visibility: hidden` 樣式。

### 2. JS 邏輯新增與重構 (`<script>`)
* **`QuizState` 狀態管理**：記錄生命值 (`lives: 3`)、當前關卡/題目、賸餘時間 (`timeLeft: 15`)、已答對數量、答錯的題目清單。
* **計時器控制器 (`startTimer`, `stopTimer`)**：使用 `setInterval` 進行倒數，每秒更新計時條，若倒數歸零觸發超時懲罰。
* **生命值控制器 (`deductLife`, `renderLives`)**：當答錯或超時，扣除一顆心，並在畫面上產生心碎動畫。
* **題型渲染器 (`renderQuestion`)**：
  * 根據當前題目的題型 (`type: 'choice' | 'classify' | 'order'`)，動態渲染不同的 HTML 操作面板。
* **特效觸發器 (`triggerShake`, `triggerParticles`)**：用 JS 動態創建粒子元素並隨機拋射，或給卡片加上 `.shake` class 並在動畫結束後移除。
* **複習系統 (`initFlashcards`)**：在測驗結束面板中，若有錯題，渲染錯題複習專區，並綁定點擊 3D 翻轉事件。

## 🔍 驗證與測試計劃

### 自動化與手動驗證項目：
1. **互動操作流暢度**：
   * 點選答案時，驗證粒子特效是否正常在點選處周圍噴灑。
   * 答錯時，驗證題目卡片是否觸發 300ms 的左右震動。
2. **計時與生命值邊界測試**：
   * 測試 15 秒倒數結束後，是否正確扣除一顆心，並自動標示正確答案、顯示解析。
   * 測試答錯 3 次後，是否能流暢切換到「挑戰失敗」畫面，且計時器停止。
3. **分類題與排序題互動性**：
   * 測試點擊卡片分類時，籃子是否產生吸收縮放動畫。
   * 測試排序題的「上移/下移」是否能即時反映在畫面上，且在點擊「提交」時正確比對順序。
4. **成就與 3D 翻轉**：
   * 測試不同得分下，是否能獲得對應的玻璃擬態徽章。
   * 測試錯題卡片點選時是否順暢翻轉 180 度，且背面的科學原理註解文字清晰、無字體穿透重疊問題。
